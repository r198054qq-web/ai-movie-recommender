# AI Movie Recommendation System

## Project Overview
This project aims to develop an AI-powered movie recommendation system using big-data similarity algorithms and the Upstage Solar LLM Agent.

## Main Features
- Search movies by title or genre
- Recommend similar movies using Jaccard similarity and MinHash/LSH
- Understand user preferences through an LLM agent
- Generate personalized movie recommendations with Upstage Solar
- Display results through a Streamlit web application

## Technologies
- Python
- Pandas
- Streamlit
- Jaccard Similarity
- MinHash / LSH
- Upstage Solar API

## Dataset
TMDB Movie Metadata Dataset
